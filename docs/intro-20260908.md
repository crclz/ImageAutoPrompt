# ImageAutoPrompt

## 从理论到工具：用 AI 画出你想要的风格

noobai / anima 的画师串与 Lora 探索

---

## 玩 AI 绘画，其实是在回答三个问题

1. **用什么模型？**
   noobai、anima、Krea 2——各有各的位置
2. **怎么控制风格？**
   画师串和 Lora，两条路
3. **怎么找到"我的"风格？**
   系统性地探索：广撒网、收网、一轮轮逼近

前两个问题，接下来几分钟就能讲清楚。
第三个问题最麻烦——它也是今天这个仓库存在的理由。

---

## 先看模型：noobai vs anima

它俩是当前画二次元最好用的两个模型，架构上的关键差异在**怎么读你的 prompt**：

- **noobai**：用 CLIP 理解提示词。CLIP 像一个词袋模型——
  词都认识，但**词和词之间的位置关系**基本管不了
- **anima**：用 Qwen（一个语言模型）理解提示词。
  它读 prompt 读得更明白，**你写什么，它更听话**

---

## 再看第三个模型：Krea 2

| | noobai | anima | Krea 2 |
|---|---|---|---|
| 二次元支持 | 好 | 好 | 较弱 |
| 推理开销 | 小 | 小 | **非常大** |
| 构图与背景 | 一般 | 一般 | **更好** |
| 内置安全 | 较宽松、更全能 | 较宽松、更全能 | 内置安全，更保守 |
| 建议 | 主力 | 主力 | 熟练后再上手 |

一句话：**先在 anima / noobai 上把玩法练熟，
想要更强的构图和背景时，再上 Krea 2。**

---

## 控制风格的两条路：画师串 vs Lora

**画师串的原理**：模型训练的时候，见过大量带画师 tag 的图。
所以生图时把画师 tag 喂给它，它就能**一定程度复现**这个画师的风格。

**Lora 的原理**：直接拿画师的图去训练，练出一个大约
几十 MB 到一两百 MB 的小文件。生图的时候把它挂上去，
风格就会带上这个画师的味道。

---

## 画师串 vs Lora：怎么选

| | 画师串 | Lora |
|---|---|---|
| 风格强烈程度 | 复现**可能不够强烈** | 复现**非常到位** |
| 小众宝藏画师 | 模型没训够就用不了 | 社区可能有人练过 → 扩展性更好 |
| 叠加 4–5 个 | **冲突概率非常低**，风格融合自然（理解是原生的） | 有冲突风险：画面不和谐、肢体出问题、光影变脏 |

各有甜点，不是谁替代谁。

---

## 模型 × 方法：组合建议

**noobai：两条路都好走**

- 能用的 Lora 数量最多（历史长、兼容广）
- 想要**更强烈、更还原**的风格 → 建议 Lora
- 画师串胜在**省事、不容易冲突**

**anima：画师串不太好用**（个人经验）

- 对画师的理解本身就弱一点
- 甜点区只有 **1–2 个画师**；从 2 个往 5 个加，
  越探索画面反而越难看

---

## 实践第一步：积累画师

去能看到画师作品的网站，挑自己喜欢的画师，然后：

1. 查到它对应的 **danbooru tag**（名字经常和 pixiv 昵称完全对不上）
2. 把它的图**喂给 AI，让 AI 描述它的风格**
   ——比如"线稿感强、色调偏冷、擅长逆光"
3. 这样选画师串的时候就有参考了

也可以完全不要参考：大范围随机地探索，让图自己说话。
两种都行，看个人。

---

## 实践第一步（另一条路）：获取 Lora

流程和积累画师类似，但**多一步下载**：

1. 挑中画师，查好名字
2. 去社区（比如 civitai）**搜对应架构的** Lora 文件
3. 下载下来，挂上用

注意"对应架构"：给 noobai 用的和给 anima 用的 Lora 不是一回事。

---

## 探索的哲学：每张图都值得单独探索

- 生活化的场景，适合这一批画师 / Lora
- 宏大的场景，适合另一批

所以有两种实践：

- **每张图从零开始**：随机地广泛探索，再收敛范围（我更偏好这种）
- **复用**自己积累的好画师串

我自己是**两种结合**着用的。

---

## 通用探索流程（画师串、Lora 都适用）

1. **从一个开始**：把画师 tag（或 Lora）插到 prompt 里合适的位置
2. **广撒网**：一轮 32 个候选，各出一张图。
   挑出喜欢的——可能喜欢这张的**人物**、那张的**氛围**
3. **从少到多，从简到繁**：先单个试 → 再两两组合 →
   再 2–3 个组合 → 再 4–5 个组合，逐轮往上加。
   组合的权重自己定：可能 1:1，也可能 1:0.8
4. **微调**：发现规律后继续逼近——
   比如 A 0.8 + B 0.2 觉得 A 太浓了，就取个中间值

这个探索空间是**平滑的、可以二分的**，所以一轮轮收敛是可行的。

---

## 关键洞察：探索是可以被优化的

回想刚才的流程：我设计了十组实验，跑完之后，
最喜欢其中三四张，不喜欢另外几张。

**根据喜欢和不喜欢，其实可以在数学上推定下一轮往哪走**：
哪些画师的权重不能再高了，哪些可以更高。

这个分析**不难，但非常繁琐**——密集的数字计算和对比，人做着累。

→ **交给大模型做。**

这就是我做这个自动工具的起因。

## 甜点一：format-anima / format-noobai

最好上手、自成一体。**你现在就可以用它。**

- 你用**自然语言**描述想要什么图，
  它写出符合模型格式的 danbooru tag prompt
- 它会自己去仓库内置的 danbooru tag 数据里**查证 tag**——
  不是瞎编的，这就是 agentic 的体现
- 一个 skill 对应一个模型的格式标准

**给 agent 的指令**

```text
帮我使用 format-anima skill 编写prompt. <粘贴多模态图片> <或者粘贴图片描述>
```

（现场演示：自然语言描述 → prompt → 跑图）

## 探索长什么样（两个真实 episode）

**画师串**（`on_table_1`，noobai）：

| 轮 | 组合 | 张数 |
|---|---|---|
| 1 | 单画师，无权重 | 24 |
| 2 | 2 画师，无权重 | 24 |

| 4 | 3 画师带权重 | 12 |

**Lora**（`firefly_swimsuit_1`）：

| 轮 | 组合 | 张数 |
|---|---|---|
| 1 | 单 Lora（1.0） | 35 |
| 2–3 | 2 Lora（1.0 + 0.6~0.7） | 24 |

| 5 | 4 Lora（0.7 / 0.6 / 0.6 / 0.4） | 24 |

从发散到收敛，Lora 和画师串一模一样——接下来把它交给大模型自动跑。

## 甜点二：civitai-lora-search

给它一个画师主页，它**一句话批量干完四件事**：
搜索 → 识别（架构适配、触发词、推荐权重）→ 下载 → 记录进你的 Lora 库。

**给 agent 的指令**

```text
帮我搜索https://www.pixiv.net/users/1960050的适合anima的lora
```

两条搜全经验，提前知道少踩坑：

- 画师 Lora 的模型名常用 **pixiv 原名**（不是罗马字）——
  所以它常和 artist-name-search 配合：先查出名字再搜
- **空格和下划线是不同写法**，都试一遍

---

## 正菜之前：先画个饼

我们的最终目的：**让大模型自动生成探索**，
一轮出一批图、读完你的反馈、自己算下一轮怎么走。

但要一轮又一轮**快速迭代**，光靠手动打字、复制粘贴是撑不住的——
prompt 的书写、组合的枚举、权重的计算、历史的记录，全都是体力活。

所以需要一个**完善的基础框架**，让这一切在框架里自动跑起来。

---

## 框架：三步接上你的 ComfyUI

| 步 | 做什么 | 说明 |
|---|---|---|
| 1 | install-environment | uv 一条命令装出 `.venv`，重组件已隔离、轻量够用 |
| 2 | setup-app-config | 告诉工具你的 ComfyUI 地址 |
| 3 | adapt-workflow | 把你的工作流**模板化**（插占位符） |

然后运行 `python server.py`——**全程唯一要手动敲的命令**。

核心原理：工具不接管你的工作流，只做**字符串替换**——
采样器、模型、分辨率全部原样保留，只把 prompt 塞进占位符。
**"把工作流模板化"是理解这个仓库的钥匙。**

---

## 正菜：episode——探索的载体

一个 **episode** = 围绕同一个 prompt 的一条优化轨迹。

每一轮（timestep）：

1. agent 写出一批 prompt，每张图和上一轮的差别都写清楚
2. 交给你的 ComfyUI 批量出图
3. 你在**网页端**给图打分（还可以逐图写评论）
4. agent 读回反馈，算出下一轮方向 → 回到 1

只需要写**正向** prompt：负向你早就按自己审美固化进工作流了。

---

## 正菜：artist-explore / lora-explore

方法论就内建在 skill 里，agent 会先和你确认关键决策再开工。
以 noobai 画师串为例的漏斗：

| 阶段 | 试什么 | 每轮张数 |
|---|---|---|
| 0 | `get_artists.py` 随机出候选（dropout 防重复） | — |
| 1 | 单画师 | 16 |
| 2 | 2 画师无权重 | 8 |
| 3–4 | 2–5 画师带权重，平衡探索与利用 | 8 |

**给 agent 的指令**

```text
在新 episode 中，帮我使用 artist-explore 探索 artist. prompt: 1girl, solo, ...
```

```text
在新 episode 中，帮我使用 lora-explore 探索 lora. prompt: 1girl, solo, ...
```

---
