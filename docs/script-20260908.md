## 【PPT 1】开场

大家好，今天我来介绍一个我自己一直在用的工具，叫 ImageAutoPrompt。

不过先不讲工具本身。我们先聊清楚两件更根本的事：AI 绘画应该怎么玩，
以及"找风格"这件事，本质上是个什么过程。
把这些想明白了，这个工具为什么长成这样，就一目了然了。

---

## 【PPT 2】三个问题

玩 AI 绘画，说到底是在回答三个问题。

第一，用什么模型？
第二，怎么控制画风？
第三，也是最难的：怎么找到属于你自己的风格？

前两个问题，接下来几分钟就能给你答案。
第三个问题没有标准答案，只能靠探索——
一次一次地跑图、看图、调整，再跑图。
而探索，恰恰是最花时间的。

所以今天的主要内容，就是怎么把"探索"这件事变快。

---

## 【PPT 3】noobai vs anima

先看模型。今天的主角是 noobai 和 anima，
它们是目前画二次元最好用的两个模型。

它俩最关键的区别，是怎么读你的提示词。

noobai 用的是 CLIP。这个东西像一个词袋模型：
里面的词它都认识，但词和词之间的位置关系，它基本管不了。

anima 用的是 Qwen，一个正经的语言模型。
所以它读 prompt 读得更明白——你写什么，它就更听话。

---

## 【PPT 4】Krea 2

除了这两个，还有一个模型叫 Krea 2，也值得知道。

它对二次元的支持不如前两个；推理开销非常大，跑起来很贵。
但它也有强项：构图和背景确实更好。

另外要特别注意，它内置了安全机制，比前两个模型更保守。
noobai 和 anima 在安全上宽松一些，换来的是更全能。

我的建议是：先在 anima 和 noobai 上把玩法练熟，
想要更强的构图和背景的时候，再上 Krea 2。

---

## 【PPT 5】两条路

那风格怎么控制？主要是两条路：画师串和 Lora。

画师串的原理是这样的：模型在训练的时候，
见过大量带画师标签的图。
所以你生图的时候把画师 tag 喂给它，
它就能在一定程度上复现这个画师的风格。

Lora 的做法更直接：拿画师的图去单独训练，
练出一个大概几十 MB 到一两百 MB 的小文件。
生图的时候把它挂上去，风格就带上了。

---

## 【PPT 6】怎么选

这两条路怎么选？我从三个方面对比。

第一，风格的强烈程度：
画师串的复现可能不够强烈；Lora 可以复现得非常到位。

第二，小众宝藏画师：
模型没训够的画师，tag 就用不了；
但社区可能有人给它练过 Lora。
所以 Lora 的扩展性更好。

第三，叠加：
四五个画师串在一起，冲突概率非常低——
因为这种理解是模型原生的，风格融合很自然。
Lora 理论上也能叠很多个，但有冲突风险：
画面不和谐、肢体出问题、光影变脏。

各有各的甜点，不是谁替代谁。

---

## 【PPT 7】模型 × 方法

再跟模型结合一下。

noobai 两条路都好走。
它能用的 Lora 数量最多，因为历史长、兼容广。
想要更强烈、更还原的风格，建议用 Lora；
画师串胜在省事、不容易冲突。

anima 的画师串不太好用，这是我的个人经验：
它对画师的理解本身就弱一点；
甜点区只有一到两个画师，
从两个往五个加，越探索画面反而越难看。

---

## 【PPT 8】积累画师

接下来讲实践。想做画师串，先得积累画师。

去能看到画师作品的网站，挑自己喜欢的画师，然后：

第一步，查它对应的 danbooru tag。
注意，这个 tag 经常和 pixiv 昵称完全对不上。

第二步，我特别推荐一个做法：
把它的图喂给 AI，让 AI 描述它的风格——
比如"线稿感强、色调偏冷、擅长逆光"。
这样你以后选画师串的时候，就有参考了。

当然，你也可以完全不要参考：
大范围随机地探索，让图自己说话。两种都行，看个人。

---

## 【PPT 9】获取 Lora

获取 Lora 的流程差不多，但多一步下载。

挑中画师、查好名字之后，
去社区——比如 civitai——搜**对应架构的** Lora 文件，
下载下来，挂上用。

注意"对应架构"这四个字：
给 noobai 用的和给 anima 用的 Lora，不是一回事。

---

## 【PPT 10】探索的哲学

再说探索的哲学。我的观点是：**每张图都值得单独探索。**

生活化的场景，适合这一批画师、这批 Lora；
宏大的场景，适合另外一批。

所以有两种实践：
一种是每张图都从零开始，随机地广撒网，再收敛——我更偏好这种；
另一种是复用自己积累的好画师串。

我自己是两种结合着用的。

---

## 【PPT 11】通用探索流程

那具体怎么探索？这套流程，画师串和 Lora 都适用。

第一步，从一个开始：
把画师 tag，或者 Lora，插到 prompt 里合适的位置。

第二步，广撒网：
一轮 32 个候选，各出一张图，挑出你喜欢的——
可能你喜欢这张的人物、那张的氛围。

第三步，从少到多、从简到繁：
先单个试；再两两组合；再两三个；再四五个，逐轮往上加。
组合的权重自己定：可能一比一，也可能一比零点八。

第四步，微调：
比如 A 权重 0.8 加 B 权重 0.2，你觉得 A 太浓了，就取个中间值。

这个探索空间是平滑的、可以二分的，
所以一轮一轮收敛，是可行的。

---

## 【PPT 12】关键洞察

现在说今天的第一个关键点。

刚才那套流程，其实是一个**可以被优化的过程**。

我设计了十组实验，跑完之后，
最喜欢其中三四张，不喜欢另外几张。
根据这些喜欢和不喜欢，
其实可以在数学上推定下一轮往哪走：
哪些画师的权重不能再高了，哪些可以更高。

这个分析不难，但非常繁琐——
全是密集的数字计算和对比，人做着累。

所以，交给大模型做。

**这就是我做这个自动工具的起因。**

## 【PPT 13】仓库登场

好，工具正式登场。先给大家一张地图，再逐个演示。

今天的顺序是：

先吃甜点——
format-anima 和 format-noobai，最好上手的两个；
civitai-lora-search，一句话批量搜索、识别、下载、记录 Lora；
artist-name-search 在背后帮忙发现关键词。

然后搭框架——
install、setup、adapt 三步，把工具接到你的 ComfyUI。

最后上正菜——
episode，加上画师串探索和 Lora 探索。
彩蛋是 free-explore，探索普通 tag 用。

---

## 【PPT 14】甜点一：format

先看甜点一。

format-anima 和 format-noobai 是最自成一体、最好上手的：
你用自然语言描述想要什么图，
它写出符合模型格式的 danbooru tag prompt。

而且它不是瞎编的——
它会自己去仓库内置的 danbooru tag 数据里查证 tag。
这就是 agentic 的体现。

一个 skill 对应一个模型的格式标准。

**【演示】** 自然语言描述 → 生成 prompt → 跑图

---

## 【PPT 15】探索长什么样

演示正菜之前，先看两个真实的 episode，感受一下探索长什么样。

第一个是画师串的：
第一轮 24 张，单画师；
第二轮 24 张，两画师无权重；
第三轮，两画师带权重；
第四轮，三画师带权重；
最后收敛在 kouda suzu 0.9、aosa 1.1、ru zhai 0.8 这个组合，
转去探索服装了。

第二个是 Lora 的：
从单 Lora 35 张，到两个、三个、四个，
最后收敛在 fkey 0.7、ningen_mame 0.7、cute2712 0.6 附近微调。

可以看到，**从发散到收敛，Lora 和画师串一模一样。**

---

## 【PPT 16】甜点二：civitai-lora-search

甜点二，civitai-lora-search。

给它一个画师主页链接，它一句话批量干完四件事：
搜索；识别——架构适配、触发词、推荐权重；
下载；记录进你的 Lora 库。

两条经验送给大家：
画师 Lora 的模型名常用 pixiv 原名，不是罗马字，
所以它经常和 artist-name-search 配合，先查出名字再搜；
还有，空格和下划线是不同的写法，都得试一遍。

**【演示】** 复制指令，30 秒左右出结果

## 【PPT 17-18】正菜：画饼 + 框架

现在上正菜。先把饼画出来。

我们的最终目的，是让大模型自动生成探索：
一轮出一批图，读完你的反馈，自己算出下一轮怎么走。

但要一轮又一轮快速迭代，
光靠手动打字、复制粘贴是撑不住的——
写 prompt、枚举组合、算权重、记历史，全是体力活。

所以需要一个完善的基础框架。框架三步：
装环境；填 ComfyUI 地址；把工作流模板化。
最后跑一个 python server.py，
这是全程唯一要手动敲的命令。

核心原理说一句：工具不接管你的工作流，只做字符串替换。
采样器、模型、分辨率全部原样保留，只把 prompt 塞进占位符。
"把工作流模板化"，是理解这个仓库的钥匙。

---

## 【PPT 19】episode

框架有了，正菜的主角是 episode。

一个 episode，就是围绕同一个 prompt 的一条优化轨迹。

每一轮是这样的：
agent 写出一批 prompt，每张图和上一轮的差别都写清楚；
交给你的 ComfyUI 批量出图；
你在网页端给图打分，还可以逐图写评论；
agent 读回反馈，算出下一轮的方向，然后进入下一轮。

顺带说一句：只需要写正向 prompt。
负向你早就按自己的审美固化进工作流了。

---

## 【PPT 20-21】explore + 收尾

最后，artist-explore 和 lora-explore。

方法论就内建在 skill 里，agent 会先和你确认关键决策，再开工。

以 noobai 的画师串为例：
单画师 16 张起步；
然后两画师、两到五画师带权重，逐轮往上；
最后一轮平衡探索和利用，收敛出最好的三个组合。

想用的话，左边这些指令，回去照抄就行。

今天就到这里。**去探索你的画风吧。**
